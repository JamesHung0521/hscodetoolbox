How to Use the HS Code Lookup Tool

Practical guidance from HS Code Toolbox

The HS Code Lookup finds the six-digit HS code for your product in seconds, free, with no sign-up. Here's how to use it well.

Search by product name

Type what your product is in plain English — "coffee," "rubber gloves," "leather shoes." The tool matches against its built-in list and shows the code or codes that fit, along with a short description so you can confirm the wording matches your item.

Search by code

Already have a code, or saw one in a supplier's file? Type the digits — for example 6403 — and the tool reads back what that heading and subheading mean. This is the fastest way to double-check a number you were handed.

Use both directions together

The reliable workflow is to go both ways. Search the product name first to get a candidate, then search that code to read its official wording. If the description lines up with your product, you've got a solid six-digit base to work from for whichever market you're shipping to.

A note on depth

The tool returns the six-digit international base. That's the right starting point for planning and comparison. For an actual customs declaration, your destination may need a longer national code (ten digits in the US, EU and China) — the six-digit base is where that process begins.
