HS Code 101

HS Code Mistakes That Cost Exporters Customs Delays

Practical guidance from HS Code Toolbox

Most shipments that sit at the border aren't held for anything dramatic. More often it's a handful of small, avoidable HS code slip-ups that cost you days and sometimes penalty fees. Here are the ones I keep seeing.

Using the English name, not the code

You'd think customs cares about what you call the product. They don't. The code is what carries the duty rate, the license and the restriction. If the description says one thing but the code points somewhere else, that's an instant examination trigger. Describe honestly, then match the code to it.

Stopping at the wrong number of digits

The six-digit base is global, but most destinations want the longer national number — ten digits in the US, EU and China. Ship with only six and the declaration gets kicked back for being incomplete. Know which depth your destination expects before you file.

Copying a code from a similar product

Two products can look almost identical and still sit in different headings. Ceramic mugs versus porcelain, a toy vs a miniature container. "Close enough" isn't a classification strategy. Check the actual heading text for your exact item instead of reusing whatever worked last time.

Ignoring the chapter notes

Every chapter has legal notes that add, exclude or refine what belongs there. The description can look perfect, and then a note quietly moves your product elsewhere. Read the notes before you commit, not after a hold.

Forgetting the destination's own rules

Even a correct code doesn't guarantee smooth passage. Some destinations add national subdivisions, require specific licenses for certain codes, or apply anti-dumping measures you didn't plan for. Check the destination's treatment before you ship, not after.

The fix starts at the quoting stage. Look the code up properly, read the notes, confirm the destination depth — and you take most of the border risk off the table.
