How to Use the Container Loading Calculator

Practical guidance from HS Code Toolbox

The Container Loading Calculator tells you how many cartons fit in a 20ft, 40ft or 40ft high-cube container — testing every orientation against both volume and weight. Here's how to use it.

Enter your carton size and weight

Put in your carton's length, width and height in centimetres, and its weight in kilograms. Use the outer box dimensions — that's what takes up space in the container, not the product's size.

Read the result per container

The calculator works out the best fit for each container type. You'll see how many cartons fit, which arrangement achieves it, and how full the container is on both volume and weight. One look tells you whether you're out of space first or over weight first.

Use the 2D view for a sanity check

The visual layout shows the real rows, columns and layers of your packing in the top, front and side views. It's the fastest way to confirm the number makes sense — not just trust a total.

Let auto-select pick the container

Not sure which box to book? Let the tool choose. It flags when a container can't take your cargo (a panel too tall, a bundle too long) and suggests the size that actually works.

Run your real numbers before you ask for quotes — you'll know exactly how much container you need, and you won't pay for a box you don't fill.
